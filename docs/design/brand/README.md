# Bizora brand (owner's choice, 2026-11-15)

The owner chose a wordmark-only logo: the name "bizora" in heavy rounded lowercase letters, with
the z and o joined. There is no separate symbol. The app icon uses the wordmark's own b, white on violet.

The wordmark was generated with an image model at the owner's request (Higgsfield, Recraft V4.1,
vector mode). The lead removed the background and cropped it to the letters. The files are clean
vector paths with no fonts, so they render the same everywhere.

Colours: ink #09071F, violet #6A00E8 (the accent for light themes), #9B5CFF (the accent for dark
themes), night #0E0B1A (dark ground).

Arabic wordmark: drawn by hand to match the English one (owner's request), not based on any font.
It reuses the English wordmark's parts: the same stroke weight, true circles for the waw's head and
for the dots (the size of the i's dot), one large rounded top corner on each upright (mirrored,
because Arabic runs right to left), and ز running into و the way z runs into o. It ships as vector
paths. Place it beside the English wordmark with a thin divider, or stack it under it.
