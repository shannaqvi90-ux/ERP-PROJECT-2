# Compliance rules

Statutory rules the product follows, each taken from a current official publication
(CLAUDE.md rule 8). Every file gives the rule, the source text quoted from the publication, the
link, the date the source was checked, and the owner's sign-off. A rule with no sign-off is not
implemented.

| File | Rule | Checked | Sign-off |
|---|---|---|---|
| [vat-trn-format.md](vat-trn-format.md) | Tax Registration Number: exactly 15 digits | 2026-10-10 | Owner, 2026-10-10 (needs-human #10) |
| [vat-rounding-and-currency.md](vat-rounding-and-currency.md) | Rounding to the fils and conversion to dirhams | 2026-10-10 | Owner, 2026-10-10 (needs-human #4) |
| [arabic-legal-name-on-documents.md](arabic-legal-name-on-documents.md) | Arabic legal name on printed documents | 2026-10-10 | Owner, 2026-10-10 (needs-human #9) |
| [e-invoicing-timeline.md](e-invoicing-timeline.md) | UAE electronic invoicing deadlines (information, no rule implemented) | 2026-10-10 | Not needed (nothing implemented) |

Owner's sign-off for #4, #9 and #10, given on 2026-10-10 in reply to the lead's sourced
recommendations: "project ka naam baad main decide karainge, baqi is k alawa jo tumhain thek lag
raha hay wo karo" ("we will decide the project name later; apart from that, do what you think is
right"). The recommendations the owner answered are the ones recorded in each file.

Official English texts of UAE tax law are published as unofficial translations; the Arabic text
prevails. Re-check each source before building VAT, ledger or invoicing modules on these rules.
