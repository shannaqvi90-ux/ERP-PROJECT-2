# Who may run each reviewed SECURITY DEFINER function (tests/Gates/security-definer-allowlist.txt),
# and which source files may name it. Each line needs a reason after '#'.
# Format: schema.function caller <who>   # reason      who = endpoint:<endpoint name> | authentication
#         schema.function source <path>  # reason      path = repository-relative file under src/
# The G1 HTTP attack traces every SQL statement the app sends and fails if one of these functions
# runs from any other caller (another endpoint, a job, outside a request). The source gate fails if
# any other file under src/ names the function.
identity.verify_sign_in caller endpoint:auth.signIn  # Sign-in proves the password for an e-mail before a tenant is known.
identity.resolve_session caller authentication  # The kernel's session authentication handler maps a token to its tenant before any endpoint runs.
identity.verify_sign_in source src/Modules/Identity/Erp.Modules.Identity/Auth/SignInService.cs  # The sign-in service, its only caller.
identity.resolve_session source src/Modules/Identity/Erp.Modules.Identity/Auth/SessionResolver.cs  # The session resolver the authentication handler calls.
identity.verify_sign_in source src/Modules/Identity/Erp.Modules.Identity/IdentitySql.cs  # Definition and grants (migrations).
identity.resolve_session source src/Modules/Identity/Erp.Modules.Identity/IdentitySql.cs  # Definition, grants and the unbound-only guard (migrations).
