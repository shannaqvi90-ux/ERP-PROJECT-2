# Files under src/ reviewed to write with a set-based statement (EF Core ExecuteUpdate or
# ExecuteDelete). Such a statement never reaches ModuleDbContext's SaveChanges checks (company
# permission, branch limits, records every branch or company shares), so a handler that ran one
# before its own permission check could change a company it only reads (critic p02 rounds 12 and
# 13: a branch of company Y closed with one ExecuteUpdate). The database's company_write_* policies
# refuse such a write on company tables; this list keeps every use reviewed as well. A new use, a
# use in a file not listed here, or fewer uses than reviewed fail the gate
# (tests/Erp.Gates.Tests/G2/G2SetBasedWriteSourceTests.cs).
# Format: <repository-relative path> <uses>  # the sets written, why set-based, why no company is reached
