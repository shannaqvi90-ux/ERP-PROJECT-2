# Unique indexes on tenant tables that leave out tenant_id. Uniqueness is per tenant: anything
# unique across the platform lets one tenant's rows decide what another may store, and the refusal
# tells it what exists. List an index here only when its values must be unique across the platform
# and cannot be chosen or guessed by a tenant, with that reason. The G1 gate fails on an unreviewed
# index and on a stale entry.
# Format: schema.table.index_name  # reason
identity.sessions.ix_sessions_token_hash  # hashes of 256-bit random session tokens the server makes; a session is looked up by its token before the tenant is known, and no request can choose a token
tenancy.tenants.ix_tenants_code  # the workspace code names a workspace on the sign-in screen, across the platform; the row is the tenant itself (tenant_id = id), and codes are made by provisioning, not by tenants
