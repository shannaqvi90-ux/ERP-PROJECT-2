# SECURITY DEFINER functions: the only code that reads across tenants. Each needs a reason.
identity.verify_sign_in(p_email text, p_proofs text[], p_source text, p_ip text, p_user_agent text, p_threshold integer, p_window_minutes integer)  # Sign-in. Without proofs: the hashing parameters (algorithm, cost, salt) of the accounts with the e-mail, or a keyed decoy, never a hash or an id. With proofs (the app's PBKDF2 of the password for each salt): the workspace of each account whose stored hash equals a proof, is active, unexpired and whose client is not paused; every other outcome is recorded in that account's own sign-in history. Answers nothing on a tenant-bound connection.
identity.resolve_session(p_token_hash bytea)  # Every request: maps the SHA-256 of a session token to its tenant and user if unexpired and unrevoked.
