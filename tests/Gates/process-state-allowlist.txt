# Process-wide state in the product's assemblies (static fields, fields of singleton services,
# cache services). Every tenant shares one process, so state that outlives a request can carry one
# tenant's data to another. Reviewed list: every entry needs a reason after '#' saying why it can
# never hold tenant data. The G1 process-state gate fails on an unreviewed or stale entry.
# Format: static|singleton <Namespace.Type>.<field>   or   service <Service.Type.FullName>

singleton Erp.Kernel.Hosting.OpenApiDocumentCache._json  # The API description generated once from code (routes, request and response types, permissions, anonymous reasons) without a request, then only read; identical for every tenant and caller and holds nothing a request sent (decision p03-identity-openapi-generated-once).

# Registration objects reached from the module catalogue, judged field by field (ReachableState).
# Each is filled by ModuleBuilder while its module's Register runs at start-up and only read
# afterwards; the G1 HTTP attack also fingerprints all reachable state before and after the
# attack and fails if any of it changed while tenants used the app.
reachable Erp.Kernel.Modules.ModuleDescriptor.Commands  # The module's command-line verbs (verb, usage text and handler from code), filled during registration and run only by the operator's command line, never by a request; identical for every tenant.
reachable Erp.Kernel.Modules.ModuleDescriptor.DbContexts  # The DbContext types the module registered (types from code), filled during registration, identical for every tenant.
reachable Erp.Kernel.Modules.ModuleDescriptor.EndpointMaps  # The module's endpoint-mapping delegates (route prefix and mapping code), filled during registration and run once while the host maps routes; the delegates and the closures they hold are walked and judged on their own.
reachable Erp.Kernel.Modules.ModuleDescriptor.IsolationProbes  # The isolation probe types the module registered (types from code), filled during registration.
reachable Erp.Kernel.Modules.ModuleDescriptor.ListBindings  # The module's list query bindings by list key, filled during registration; each binding is immutable (Column and InMemory return a new binding) and is walked and judged field by field.
reachable Erp.Kernel.Modules.ModuleDescriptor.ListsServedBy  # Which other module's list serves each of this module's lists (list keys from code), filled during registration and read once when the catalogue resolves bindings at start-up; identical for every tenant.
reachable Erp.Kernel.Modules.ModuleDescriptor.Lists  # The module's list definitions (immutable records from code), filled during registration.
reachable Erp.Kernel.Modules.ModuleDescriptor.Menu  # The module's menu entries (immutable records from code), filled during registration.
reachable Erp.Kernel.Modules.ModuleDescriptor.Permissions  # The permission definitions the module declares in code, filled during registration.
reachable Erp.Kernel.Modules.ModuleDescriptor.Seeders  # The seeder types the module registered (types from code), filled during registration.
reachable Erp.Kernel.Modules.ModuleDescriptor.ListRowReaders  # Readers of the module's list rows by list key (delegates from code that read rows exactly as the list endpoint does, for reports' print and export), filled during registration; the delegates and the closures they hold are walked and judged on their own.
reachable Erp.Kernel.Modules.ModuleDescriptor.Reports  # The module's report registrations (immutable report definitions and source types from code), filled during registration; each registration is walked and judged field by field.
