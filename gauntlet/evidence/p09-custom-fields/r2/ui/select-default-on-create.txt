The screen sends default:null although the default list shows the chosen option; the field is saved with no default (customfields.definitions.default_value NULL).
Same with ui/ui2.mjs + ui3.mjs: "Incoterm" created with FOB chosen -> default_value NULL; "Payment terms" with "Net 30" chosen -> NULL.
Editing the saved field afterwards and choosing FOB saves it (default_value 'fOB').
The API itself takes a default by label on creation (api: POST select "Delivery mode" default "Air" -> 201, default "air").
Option values made from upper-case labels: EXW -> "eXW", FOB -> "fOB", CIF -> "cIF", MSC -> "mSC" (api/r1gaps-out.txt).
