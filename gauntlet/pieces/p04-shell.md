# p04 — English/Arabic app shell

- Dense, keyboard-first business layout in the Dynamics 365 manner: top bar, module
  navigation, breadcrumbs, workspace, status line.
- Command palette (open any screen, record or action by typing), global shortcuts with a
  shortcut help sheet, predictable focus, every action reachable without a mouse.
- English and Arabic switch in one step, persisted per user, full right-to-left mirroring
  (layout, icons that imply direction, tables, forms), an Arabic-capable font, number and
  date formatting per locale.
- Printed documents: a print layout base that renders English and Arabic (right-to-left)
  correctly, used later by reports.
- Every string in per-module English and Arabic resource files; no hard-coded text.
- Accessibility basics: labels, contrast, focus rings.

Compared against Odoo: switch to Arabic; reach a named screen by keyboard only.
