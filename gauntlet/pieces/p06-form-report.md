# p06 — Form and report framework

- Form component every module reuses: sections and tabs, field types (text, multiline,
  decimal number, money, date, boolean, select, lookup to another record), validation from
  the server, dirty tracking with leave warnings, save and discard by keyboard, next and
  previous record, read-only by permission, right-to-left in Arabic.
- Report framework: report definitions with parameters, grouping and totals, on-screen view,
  print and PDF in English and Arabic with correct right-to-left layout, export.
- Both work through the documented API.

Compared against Odoo: edit and save a record; print a list report in Arabic.
